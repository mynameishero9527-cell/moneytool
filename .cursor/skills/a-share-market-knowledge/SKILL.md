# A 股市场机制速查

这些是写规则和适配器时会直接用到的事实。与需求文档冲突时以需求为准，但需求里的默认值多数来源于此。

## 交易时段

| 时段 | 时间 | 说明 |
| --- | --- | --- |
| 开盘集合竞价 | 9:15–9:25 | 9:15–9:20 可撤单，9:20–9:25 不可撤单；9:25 产生开盘价 |
| 连续竞价 | 9:30–11:30、13:00–15:00 | 需求的 5 个分段都在这里 |
| 收盘集合竞价 | 14:57–15:00 | 沪深主板、创业板、科创板都有；14:57 后不可撤单 |
| 盘后固定价格 | 15:05–15:30 | 仅科创板、创业板；成交计入当日成交量但不影响收盘价 |

- 沪深无半日市。休市日以交易所公告为准，临时休市极少见但要能配置。
- 北交所交易规则不同（30% 涨跌幅），本工具不含北交所。
- T+1：当日买入次日才能卖。工具不做交易，但影响「买点」文案：当日买入不能当日卖出，卖点条件至少次日生效。

## 涨跌幅限制

| 品种 | 限制 | 识别 |
| --- | --- | --- |
| 沪深主板普通股 | ±10% | 代码 60xxxx、000xxx、001xxx、002xxx、003xxx |
| 创业板 | ±20% | 300xxx、301xxx |
| 科创板 | ±20% | 688xxx、689xxx |
| ST、\*ST（主板） | ±5% | 名称前缀 ST / \*ST |
| ST（创业板、科创板） | ±20% | 与普通股相同 |
| 新股上市首日 | 主板 44% / −36%；创业板、科创板前 5 日无限制 | 上市日起算 |
| 退市整理期 | ±10%，首日无限制 | 名称含「退」 |

- 涨跌停价 = 前收盘 × (1 ± 限制)，四舍五入到 0.01。用交易所公布的涨跌停价字段，不自己算，避免四舍五入差异。
- **涨停封板**：收盘价 = 涨停价。**炸板**：盘中触及涨停价但收盘低于涨停价。**一字板**：开盘价 = 收盘价 = 涨停价（或跌停价）且全天成交极少。**天地板**：盘中涨停后收盘跌停。
- 连板计数按连续涨停封板日；创业板和科创板 20% 一板相当于主板两板，比较连板强度时按涨幅而不是板数。

## 停复牌与特殊状态

- 停牌日无成交、无行情。需求 11.3：停牌日在窗口计算里跳过，不用 0 填；复牌首日不参与排名。
- 长期停牌（≥ 20 交易日）复牌常有补涨补跌，复牌首日涨跌幅可能极端。
- ST 是风险警示，\*ST 是退市风险警示。判断用当日名称，历史要用名称变更表按日期还原，不能用今天的名称回填。
- 退市整理期股票不进入任何名单。
- 新股：上市不满 5 交易日不排名，不满 20 交易日不计入全 A 等权（需求 11.3、6.1）。

## 资金流分档（东方财富口径）

| 档 | 单笔成交金额 |
| --- | --- |
| 超大单 | ≥ 100 万元 |
| 大单 | 20–100 万元 |
| 中单 | 5–20 万元 |
| 小单 | < 5 万元 |

- 主力净流入 = 超大单净 + 大单净。散户对应小单，中单常被忽略但需求要求保留。
- 方向按主动买卖（以卖一价成交为主动买入、以买一价成交为主动卖出）。这是行情商的估算，不是账户级真实资金。所有页面必须标「估算」。
- 全市场净流入求和恒为负或接近零（每笔成交买卖相等，主动方分类导致的偏差），所以「市场流入份额」分母用正值之和（需求 6.1）。
- 涨停封板时买单排队不成交，主力净流入被封单扭曲；一字板几乎无成交。需求 8.1 的处理源于此。

## 板块分类

- **申万行业**：2021 版一级 31 个、二级 134 个、三级 346 个。一只股票只属于一个三级，向上唯一映射到二级、一级。成分每季度调整，历史成分需要按日期取。
- **中信行业**：一级 30 个，与申万不一一对应。本工具只用申万，不混。
- **概念板块**：东方财富、同花顺各自定义，一只股票可属多个概念，成分变动频繁且无历史披露。每日快照落库是唯一可靠办法。
- 概念与行业的关系不固定，需求 8.3 的「主导行业」用成分股成交额占比最高的一级行业近似。

| 指数 | 代码 | 覆盖 |
| --- | --- | --- |
| 上证 50 | 000016 | 沪市大盘 50 |
| 沪深 300 | 000300 | 沪深大盘 300 |
| 中证 500 | 000905 | 300 之后的 500 |
| 中证 1000 | 000852 | 800 之后的 1000 |
| 中证 2000 | 932000 | 1800 之后的 2000 |
| 创业板指 | 399006 | 创业板 100 |
| 科创 50 | 000688 | 科创板 50 |

- 沪深 300、中证 500、1000 互斥且覆盖前 1800；中证 2000 覆盖 1801–3800。一只股票最多同时属于一个规模指数，加上可能的创业板指或科创 50。
- 成分每半年（6 月、12 月第二个星期五后的下一交易日）调整，中证指数公司提前公告。用纳入日期建生效区间。
- **全 A 等权**：本工具自算，见需求 6.1 口径（剔除新股、ST、退市整理，不含北交所，停牌不计）。不用中证全指或万得全 A 代替，两者是市值加权。

## 北向资金披露（2024-08-19 起）

- 不再披露实时买入卖出金额和净流入；不再披露个股每日买卖数据。
- 收盘后披露：沪股通、深股通各自成交总额与总笔数、ETF 成交总额、前十大成交活跃证券名单与成交总额。
- 每季度第 5 个交易日披露上季度末个股持股数量。
- 额度余额 ≥ 30% 显示「额度充足」，< 30% 才公布余额。
- 所以任何「北向今日净买入某股 X 亿」的免费数据都是推算或过期口径，不进产品（需求 4.2、12）。

## 常见口径陷阱

- **前复权 / 后复权**：算涨跌幅和相对强度用前复权或直接用 `pct_chg` 字段；算价格位置（250 日区间、回撤）必须用复权价，否则分红除权会被当成下跌。全项目统一后复权价算区间指标，展示用不复权价。
- **换手率**：总股本换手与流通股本换手差数倍。免费源多为流通股本口径，需求要求自由流通口径，近似并标注。
- **成交额单位**：东财万元、Baostock 元、Tushare 千元。适配器标准化为元。
- **涨跌幅**：交易所按前收盘价算，含除权日的调整。用源字段，不自己用收盘价差算。
- **交易日历**：周末和法定假日之外还有调休上班日不开市（如春节后周日）。用 Baostock 或交易所日历，不用 `weekday()`。
- **代码前缀**：6 开头沪市，0 / 3 开头深市，8 / 4 开头北交所（排除），688 科创板。ETF、可转债、B 股代码段不同，接入时按证券类型过滤只留 A 股。
