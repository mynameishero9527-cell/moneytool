# UI 设计规范

产品是给自己看盘的个人投资者用的分析工具，信息密度高、判断依据要一眼可见。设计目标是「看清楚」，不是「好看」。所有页面按需求 10 节的结构，行动清单和看板是每天用得最多的两页。

## 基本原则

- 数字优先：每个格子先放数字，再放标签。数字用等宽数字字体（`font-variant-numeric: tabular-nums`）。
- 一屏看完：看板一行一个板块，默认视图不换行、不折行。桌面 1440 宽下一屏放下 31 个一级行业。
- 证据可展开：任何标签点开都能看到命中了哪几条规则、当日值、阈值。用同一个「证据卡片」组件。
- 状态可辨：盘中 / 已确认 / 未经对账 / 数据缺失 / 盘中疑似迁移，用固定的角标，不靠颜色单独区分。
- 不诱导：不用大红按钮、不用箭头动画、不用「买入」「卖出」大字。动作标签用中性词「买入关注」「卖出关注」，旁边永远带「复核」含义。

## 颜色

A 股惯例：**红涨绿跌**。所有涨跌幅、净流入正负都按这个。不要用国际习惯的绿涨红跌。

| 用途 | 色值（浅色主题） | 说明 |
| --- | --- | --- |
| 上涨 / 净流入 | `#D9363E` | 红 |
| 下跌 / 净流出 | `#1F9D55` | 绿 |
| 中性 / 零 | `#6B7280` | 灰 |
| 主文字 | `#111827` | |
| 次文字 | `#6B7280` | |
| 边框 / 分隔 | `#E5E7EB` | |
| 背景 | `#FFFFFF`，卡片 `#F9FAFB` | |
| 盘中标记 | `#F59E0B` 琥珀角标 | 文字「盘中」 |
| 数据缺失 | `#9CA3AF` 斜线纹理 + 文字「缺失」 | 不留空白 |

六阶段固定配色，全站一致，用在阶段徽标、阶段时间线、多板块对比的线色带：

| 阶段 | 色值 | 含义 |
| --- | --- | --- |
| 冰点 | `#93C5FD` 浅蓝 | 冷 |
| 启动 | `#FCD34D` 黄 | 刚亮 |
| 扩散加速 | `#FB923C` 橙 | 升温；前半段实心，后半段斜纹 |
| 高潮拥挤 | `#DC2626` 深红 | 过热 |
| 分歧背离 | `#A855F7` 紫 | 矛盾 |
| 退潮 | `#64748B` 蓝灰 | 退 |

支持深色主题时只换背景与文字层级，阶段色和涨跌色不变。

## 排版与密度

- 字号：正文 13px，表格 12px，标题 15px，页面标题 18px。不用更大的字。
- 表格行高 32px，紧凑模式 28px。列宽固定，数字右对齐，文本左对齐。
- 金额单位统一「亿」，保留 2 位；比例保留 1 位加 `%`；相对强度用百分点，带正负号。
- 板块名、股票名后跟代码时代码用次文字色，字号小 1px。

## 关键组件

### 阶段徽标 `StageBadge`
圆角 4px，背景为阶段色 15% 透明度，文字为阶段色加深。附加标记以后缀角标显示：`疑似→启动`、`异常迁移`、`盘中`。

### 证据卡片 `EvidenceCard`
输入规则引擎的 `evidence[]` JSON。每条一行：规则名 | 指标 | 当日值 | 阈值 | ✓/✗。命中的行正常显示，未命中的行灰色但不隐藏。卡片底部固定显示：依据板块、阶段与停留天数、参数版本。

### 身份标签行 `IdentityTags`
资金体量、流通市值、指数、交易板块、概念股、控盘风险、历史暴涨暴跌。中性灰底；控盘风险和历史暴涨暴跌用描边红，不用实心红，悬停显示命中条目。

### 动作条目 `ActionItem`
一行展示：股票名 + 代码 | 身份标签 | 依据板块（概念来源标「概念股」+ 概念名）| 阶段徽标 | 留存 | 结构分 | 展开箭头。展开后是证据卡片 + 失效条件 + 买点/卖点条件对勾列表。

### 多板块对比图
ECharts 折线，每条线的颜色是板块的自定义色（不是阶段色），线下方的阶段色带展示各日阶段。悬停 tooltip 列出所有板块的当日值、阶段、市场份额。Y 轴切换用分段控件放图右上。

## 文案

- 标签名以需求 4.3 为准：规避股、买入关注、卖出关注、持有观察、跟踪中、低位企稳、先行透支、炒作倾向、历史暴涨暴跌、控盘风险。
- 禁用词：最佳、必涨、稳赚、清仓、满仓、杀散户、庄家、主力（作为动词）。「主力净流入」是数据字段名可以用。
- 空状态写原因：「无主线：今日全市场净流出」「历史不足：资金流回补至 2025-03，归因需 5 年」。
- 每页底部固定一行：「分析工具，不构成投资建议；资金流为行情商估算；历史统计不代表未来结果。」

## 响应式

- ≥ 1280：看板全列。
- 768–1280：隐藏 5 日斜率、资金集中度、形态列，其余保留。
- < 768：看板只留阶段、板块名、一日变化、市场份额；行动清单一行两段。
- 任何宽度下「看板 → 板块 → 个股 → 看懂为何」路径不能断。

## 检查清单

改完页面对照：红涨绿跌是否正确；阶段色是否与上表一致；每个数字是否带口径角标；证据是否可展开；禁用词是否出现；空状态是否写了原因。
